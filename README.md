# Aslam Chicken - Greater Noida

Static site: HTML, CSS, vanilla JS. No build step. Open index.html or upload the folder to any host.

## Structure
- index.html
- css/style.css
- js/main.js
- assets/images/ (add your photos and logo)
- robots.txt, sitemap.xml

## Before launch
1. Replace https://www.example.com in index.html (canonical), robots.txt and sitemap.xml with the real domain.
2. Replace every yellow [to be confirmed] placeholder (address, hours, phone, menu dishes).
3. Add real photos in assets/images and swap the .slot placeholders for <img> tags.
4. Add the Google Maps iframe in the Visit section.
5. Add address, phone and hours to the JSON-LD block only once verified.
6. Point the Order Now and Explore Full Menu buttons to the real links.
